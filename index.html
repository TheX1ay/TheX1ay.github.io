About

I work on question answering over virtual knowledge graphs (VKGs), where a SPARQL query can be syntactically valid, execute without error, and still return a wrong or empty answer. My research treats these silent failures as the central problem rather than an edge case: I build pipelines that diagnose why a query failed, verify candidates before trusting them, and abstain when no reliable signal exists.

More broadly I am interested in the reliability and evaluation of LLM agents over structured data — the gap between “the system ran” and “the system was right”.

Research

A VKG exposes an ontology through a mapping layer that does not cover every predicate. So these systems break at retrieval, not at generation — and they break silently.

01

Navigating virtual knowledge graphs

An active-ontology pipeline: construct an ontology view, index its elements, link question mentions, expand candidate subgraphs iteratively, rerank them, and only then emit executable SPARQL. The claim is that constraining the search space before generation removes most of the failure modes that post-hoc prompting cannot.

Navigate-VKG · Paper

02

Triaging silent failures

ATTEST routes each failure by the diagnostic signal it actually exposes: sparse ontology targets go to iterative repair, dense targets to a single-shot direct probe. A deterministic, zero-LLM verifier catches AST-level errors before execution; failures with no usable signal are admitted rather than retried. Successful repairs are indexed by query skeleton and error-code multiset, so transfer flows across structures rather than exact matches.
